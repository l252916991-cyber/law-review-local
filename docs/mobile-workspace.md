# 独立移动工作台

手机端使用 `/mobile`，独立加载 `mobile.html`、`mobile.css` 和 `mobile.js`。桌面端继续使用 `/`。两端共用 `shared.js` 的请求、错误处理和安全文本渲染，不在浏览器持久化访问令牌。

入口脚本只在页面加载时选择界面，900px 及以下默认进入手机版。`?ui=mobile`、`?ui=desktop` 和 `?ui=auto` 分别指定手机版、桌面版和跟随设备；用户选择保存在 `lexvault-ui`。横竖屏切换不会重定向正在编辑的页面。显式访问 `/mobile` 会保留手机版偏好，供统一身份登录回调后恢复。

手机端顶部提供案件切换与更多操作，底部提供总览、卷宗、证据和问答。阅卷任务与导出从更多菜单进入。页面使用独立滚动区和底部安全区；详情使用原生对话框，避免桌面表格与侧栏占据手机首屏。

部署仍需遵守现有 Host、HTTPS、认证和反向代理约束。手机上的 `127.0.0.1` 指向手机自身，不能访问电脑上的预览；真机验证需要可达的部署地址及合法的 Host 配置。本机免登录模式不因增加手机版而放开远程访问。

验证命令以 `.github/workflows/test.yml` 为准，所有顶层前端脚本均执行 `node --check`。`tests/test_mobile_ui.py` 覆盖入口模式、同源认证边界、静态安全头、共用错误处理和桌面案件切换乱序响应。桌面模拟不能替代真机 Safari/Chrome 的文件选择、软键盘与系统下载验收。
