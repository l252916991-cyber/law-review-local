## 2. 口径校正（先做，否则结论不可用）

1. **「10000题 v1」与「v2」是同一结果**：两份 `summary.json` 的 `mean_score_all` 均为
   `0.5675196398195245`，`full_score` 3156、`zero_score` 2028、20 类逐项相同，仅延迟不同。
   temperature=0 的确定性重跑，不能当作两次独立测量。
2. **v1 的 3-4=86.71% 在任何产物中都不存在**：10k 两份均为 86.23%，`benchmark_1000_test` 为 86.14%，
   `benchmark_2000_test` 为 87.28%。报告前需核对来源（可能是旧评分版本）。
3. **「1000题 / 2000题」是同一管线的分层子样本**（每类 50/100 题）。单类 n=50 时比例指标的 95% 置信区间约 ±14pp；
   1-1 在 10k 为 30.4%、在 1000 题切片为 36.1%，是抽样波动而非改进。**不要用这两列选择策略。**
4. **均分是 20 类等权平均**：每类占 5%，某类提升 10pp = 均分 +0.5pp。
5. `benchmarks/lawbench/METRICS_MAPPING.json` 已修正为与 `app/benchmark_metrics.py` 的
   `LAW_BENCH_METRICS` 一致，并标注 2-1/2-5/2-6/2-10/3-1/3-3/3-7 为本地近似口径。

## 7. 实验纪律

- 开发集每类 ≥200 题，另有独立确认集；报告 paired delta 与 bootstrap 区间，不报单点均值。
- 锚点 50 题的结果不得外推（第 5 节是反例）。
- 报告分列「能力提升 / 管线后处理 / 评分口径修正」；3-3 归一化与 2-7 抽取必须标注为评测增强。
- 保留每次调用的原始请求、回答、耗时、失败与截断；不按参考答案挑回答。
