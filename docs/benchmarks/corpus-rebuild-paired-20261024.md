# 法条库重建与 1000 题配对实测（2026-10-24）

配置：`Qwythos-9B-v2-OptiQ-4bit`（oMLX，safe 守卫、并发 1、`--no-cache`）、`lawbench-task-guided-v4`、`lawbench-local-v3`、temperature 0、max_tokens 1600、timeout 240、retry 0、每类 50 题（1000 题，seed 42）。两臂同模型、同题、同提示、同评分器，**唯一变量是法条库**。语料为 [重建并冻结的 canonical 库](corpus-rebuild-paired-plan-20261024.md)：66 份官方公布文本、7,587 条，manifest SHA-256 `ba29eae6738945042edce1eaae159674240f0837b64857375ef845cbabdfefec`，1-1 条号覆盖 **500/500（100%）**。配对实验执行时语料为 64 份/7,571 条、覆盖 492/500；其后补齐 1988/2004 宪法修正案，覆盖达到 500/500，本表数字仍是当时快照的实测值。

## 3. 与 2026-09-14「63.32%」的分解

63.32% 的口径是 **8-bit + canonical 85 部法条库**；本次是 **4-bit + 无法条库**。两者不能直接相加或替换，可分解为：

| 来源 | 估计 | 依据 |
| --- | ---: | --- |
| 4-bit vs 8-bit | **约 −0.98pp** | 去掉受语料影响的 1-1/3-2 后，18 项平均差 −0.98pp（最大回退 3-7 −5.40、2-8 −3.40，最大提升 2-10 +2.21） |
| 法条库 | **约 +3.7～4.0pp** | 本次配对实测 +3.68pp（1-1 +60.66÷20=+3.03、3-2 +13.00÷20=+0.65） |
| 语料覆盖率差异（98.4% vs 当时 100%） | 约 −0.1pp | 当时缺 8 道宪法修正案题；后续已补齐至 500/500 |

按此分解，4-bit + 有库的期望约为 **62.1～62.5%**，与实测的有库臂 62.49% 一致。

## 4. 口径与限制

1. 混合均分是 20 类等权平均，不是准确率，也不是官方 LawBench 榜单分。
2. 1000 题是按类分层抽取的子样本（每类 50 题，seed 42），不是随机全量；同一批题两臂配对，不能用它推断其它题集的绝对分。
3. 配对时的语料覆盖为 98.4%（缺 1988/2004 宪法修正案 8 题）；**2026-10-26 已补齐至 500/500（66 份、7,587 条）**，本表未重跑，数字对应当时快照。基础语料有 17 份官方来源链接失效，已如实登记。
4. 未做独立人工或律师评审；评分器为项目本地近似实现（`lawbench-local-v3`），只与同口径结果可比。
5. 2026-09-14 那套语料已不可逐字节复现（官方源改版），本表按同口径重估，不作「复现 63.32%」声明。

## 5. 对「要不要上 27B」的含义

- 语料这一项已吃满（覆盖 500/500；配对时 98.4% 的增益为 +3.68pp）；剩下的差距主要是模型能力本身，4-bit 量化代价约 1pp。
- 可比的换模型证据：35B 4-bit 在与语料无关的 5 个任务上平均 **+3.26pp**（1-2 +8.20、2-1 +11.52、2-2 +2.60、2-3 −2.23、2-4 −3.80），有涨有跌。
- 因此 27B 4-bit 的合理预期是 **+1～+3pp**，代价是约 17GB 权重、safe 守卫 17.2GB 顶格、全量万题 15～20 小时。
- **建议**：先在本次同一套 1000 题上跑 27B 一臂（约 40 分钟），确认 1-2/2-1/3-1/3-6 稳定上涨、2-3/2-4 不回退，再决定是否跑全量；不要在未配对的情况下直接烧全量。
