# 3-8 专项微调：训练数据可行性审计

日期：2026-09-13。状态：**审计完成，结论 GO（附条件）**；训练尚未启动，须按第 5 节方案另行授权执行。
本审计只读评测集题面用于量化泄漏，属于数据工程，不属于模型推理路径；评测参考答案未进入任何训练或示例用途。

## 1. 结论

**可以进入小规模 LoRA 试验**，依据：候选数据许可宽松（Apache-2.0）、来源为真实咨询问答（分布内，
与 2-2 同质合成数据失败线相对照）、与 LawBench 3-8 全部 500 题的泄漏可忽略（精确 0、近重复 1）、
清洗后规模足以支撑 3–8K 条试验。前提条件：按第 4 节过滤、按第 5 节冻结划分。

## 3. 泄漏审计（对 LawBench 3-8 全部 500 题，scripts/audit_38_sft_data.py）

方法：归一化精确匹配 + 对称字符 8-gram containment（近重复阈值 0.5，观察区 0.3）。

| 候选池 | 条数 | 精确重复 | 近重复(≥0.5) | 观察区(0.3–0.5) |
|---|---:|---:|---:|---:|
| DISC Pair-QA | 79,692 | **0** | **1** | 4 |
| DISC Triplet-QA | 23,331 | 0 | 0 | 0 |
| lawyer_llama 咨询类 | 14,476 | 0 | 0 | 0 |

人工核对全部 5 条边缘对：`5620` 与 `3-8_0462` 只是共享"婚前/婚后财产"术语（嫁妆 vs 房贷首付，
实质不同问题）；`51278`/`51631` 与 `3-8_0004` 是**同一案件事实的考试题式改写**，训练前剔除。
结论：**不存在大规模同源泄漏**；虽然 DISC 与 LawBench 在论文口径上可能与 LAIC2018 相关，
实测 8-gram 级几乎无重叠，二者使用了不同咨询问题。剔除 1+4 条后泄漏可忽略。

## 4. 质量过滤漏斗（规则可复现，见脚本）

| 池 | n | 考试题式（剔除） | 答案截断（剔除） | 答案含《法》第X条引用 | 清洗后 |
|---|---:|---:|---:|---:|---:|
| DISC Pair-QA | 79,692 | 5,177 (6.5%) | 10,583 (13.3%) | 42,012 (52.7%) | **≈63,927**（含引用 ≈33,000） |
| lawyer_llama 咨询类 | 14,476 | 0 | 345 (2.4%) | 1,114 (7.7%) | ≈14,131 |

人工抽样（Pair-QA 5 条 + lawyer_llama 3 条）：Pair-QA 多数结构化、常带引用，风格与 3-8
参考答案（结论+条文）同向，但存在引用牵强例（如以《宪法》第 89 条论证部门问责）；lawyer_llama
为真实口语咨询但答案质量参差（1 例把"养老保险未满十五年"误解为"儿童保险"）。**引用率应作为
训练池分层维度**：主力池用"含引用"子集训练"回答→法律依据"结构，其余可选作鲁棒性数据。
长度：Pair-QA 答案 p50 263 字 / p95 734 字，与 3-8 参考答案（中位 396 字）同量级。

## 5. 冻结划分方案（训练启动前固化，写入 manifest）

1. **评测隔离（硬规则）**：LawBench 3-8 全部 500 题（含 dev20 / confirm20 / conf10 / 50 题锚点裁决集）
   的题面与参考答案一律不进入训练、示例或验证；全量 500 题仅作回归基准（历史已分析，结果按
   "全量回归"口径报告，不算盲测）。
2. **外部未见测试集**：从清洗后的 Pair-QA 池按固定 seed 留出 **200 条 holdout**（不训练），
   作为"真正未见的外部咨询问题"泛化度量；另留 200 条作训练侧验证（早停/调参）。
3. **训练池**：Pair-QA 清洗 + 含引用子集分层；试验规模 3–8K 条（2-2 线 480 条同质合成即产生
   强效应，真实数据更稳，从小规模起步）。
4. 训练池、两个留出集、评测集四者的交集必须为空并写入 manifest（question 归一化哈希互检）。

## 6. LoRA 试验设计要点（沿用 2-2 线踩实的坑）

4bit 基座 + `--grad-checkpoint`（峰值 ~9.4GB）+ **text 格式预渲染**（评测同款模板逐字节，
`enable_thinking=False`、闭合 think 块）+ `serve_adapter.py` 包装器（mlx_lm server 的
adapter-path bug）；训练前先"背诵测试"验证 adapter 生效。对照臂 = 当前生产提示 A，同题同参数；
除 LawBench 回归外，**必须抽查其他任务小样本（如 2-2 / 2-7 / 1-2）检测退化**——2-2 线的
先验坍塌表现为跨题标签误触发，本线同类风险是咨询语气/结构外溢到其他自由文本任务。

## 7. 风险与限制

- 训练目标是 ROUGE-L 对齐的参考风格；需在 LawBench 回归与外部 holdout 双口径下检查是否
  只学会了表面结构。
- Pair-QA 答案质量无人工金标，只能规则过滤 + 抽样核查；错误答案进入训练的风险与 2-2 的
  教训同源，靠分层和规模控制。
- 目前证据仅支持"换一种提示尚未带来可靠提升"（neworg-v1 未过锚点裁决）；微调是下一项
  待检验假设，不是已确定有效的方案。
