## 与旧输入的关系

原测试的“至少 71 份、19 次合并、1 次民法典边界差异”指向一组未能恢复的旧来源组合。本次登记的是 **不同资产身份**：七个明确来源目录、71 个唯一公布版本，输入间无重复键，也没有那处旧边界差异。此前在 66 份资产上得到的两项失败及其完整矩阵报告保留；新清单通过不表示旧组合已复现。

默认测试继续保留旧目录发现方式及原有 `>=71`、`19`、`1` 断言。只有显式设置 `LAW_REVIEW_CORPUS_REGRESSION_ROOT` 才采用本次独立契约：先核对七份 manifest 身份、全部文档与原文摘要，再校验精确公布数量、总条数、审计分类、重建后的完整文档集合摘要、版本唯一性、边界及检索。注册资产缺失或被改动直接失败，不退回 skip；未登记目录不参与构建。

合成回归继续独立覆盖重复归并、来源优先级、实质冲突拒收和边界泄漏选择，不用重下的干净文本伪造旧缺陷。修正案第 52 条中的“第七节”属于其真实嵌入正文，现有启发式结构巡检会将其列入 `structural_leaks`；须结合版本及显式 `embedded_articles` 记录判读，不能删除该正文以取得零告警。

## 复验

将清单中的七个来源目录放入新的私有根目录，禁止覆盖现有 `output/score85/`。新获取的五份文本使用更新后的 `scripts/build_legal_corpus.py --source <ID> --output <新目录>` 构建，再用 `--verify` 检查；其余两份冻结来源按 manifest 摘要从获准归档恢复。

```sh
LAW_REVIEW_CORPUS_REGRESSION_ROOT=/absolute/private/frozen-inputs \
uv run --locked pytest tests/test_corpus_audit.py tests/test_corpus_canonical.py \
  tests/test_corpus_regression_inputs.py tests/test_legal_corpus.py tests/test_build_npc_corpus.py
```

完整矩阵沿用项目 CI 的隔离数据、禁网、覆盖率和独立 M2 解释器参数，并显式传入同一个冻结根目录。没有该版本资产的源码包结果、旧资产复验结果和本次 71 份快照结果分别记录。

这是历史检索/回归快照，内容最新公布版本仍为 2023-12-29，不能将 2026 年下载时间表述为法律现行性。目标律所实际法条配置、适用版本和现行性仍需 U1 业务验收确认。
