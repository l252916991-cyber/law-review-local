## 关键结论

1. **唯一变化是 3-2（+11.41pp）**，来自采纳的词法 statutory RAG（35.74→47.25 的全量配对
   +11.51pp 在此复现，量级一致）。**其余 19 个任务逐题完全一致（Δ=0.00）**——temperature 0
   下确定性复现，且证明 3-2 的 RAG 采纳**零外溢**，是干净的受控更新。
2. **混合均分 +0.57pp = 3-2 单任务增益 ÷ 20**，与预期完全吻合，没有意外的连锁效应。
3. **3-8 无变化（20.57%）**：本次 10k 是 8bit 生产配置、**不挂 adapter**，与 3-8 的 4bit
   adapter 实验相互独立。3-8 的 adapter 效果只由它自己的 4bit on/off 配对衡量（−3.01pp）。
