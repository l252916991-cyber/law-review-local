# 3-8 LoRA 首轮（round-1）结果：负结果归档

日期：2026-09-13。结论：**未通过验收，不接入、不扩 8K、不调参续跑**。冻结配置见
`3-8-sft-round1-plan.md`；本文件记录实际执行、偏离与归因。所有产物在
`output/sft-38-v1/`（adapter/checkpoint/日志）与 `campaign-e2e-dense/runs/dev20-38-sft-lora-*`。

## 实际执行与冻结配置的偏离（均为被迫，非调参）

| 项 | 冻结值 | 实际 | 原因 |
|---|---|---|---|
| max-seq / batch | 1536 / 4 | **512 / 1** | GPU OOM 实测上限 ≈512 token/步（batch2×512、batch1×1024 均炸；M4 Pro 24GB wired 上限） |
| iters | 750（≈1 epoch） | **2050 / 3000（0.68 epoch）中断** | 训练 GPU wired 17GB 挤压系统内存（free 反复 <1GB），按 2-2 整机卡死教训主动止损 |
| checkpoint | 按 valid loss 选 | **0002000**（唯一完整 val loss 点 0.851） | 训练日志因管道缓冲丢失早期 eval 行；0002000 为最后保存点且 train loss 仍在下降 |

## 验收结果

| # | 验收项 | 结果 |
|---|---|---|
| 1 | 背诵测试 | **不适用**：0.68 epoch 未到背诵过拟合区（2-2 需 ~3.75 epoch）。on/off 输出与训练答案 8-gram 重合 0.103 vs 0.075，法条名命中 3/5 vs 2/5，区分度弱 |
| 2 | 3-8 dev20 配对 | **失败：on 15.19 vs off 17.97，−2.79pp**（9 胜 11 负，95%CI [−7.35, +1.78]，统一 normalize 口径，零技术失败） |
| 3 | 其他任务退化 | **1-2 严重退化：off 90.0 → on 60.0（−30pp，dev10 配对）**；2-2/2-7 未跑——1-2 已足以判死 |
| 4 | 人工法律质量 | on 臂掉分最大 3 题全读：**2 题复读循环**（同一句重复 20+ 次至 length 截断）、1 题法条堆砌偏题；引用率 20/20→12/20、答案长度中位 821→308 字 |
| 5 | 路由隔离 | **不安全**：挂 adapter 的端口上 1-2 掉 30pp，共享端口不可行；双端口隔离方案本身可行但无部署价值 |

## 归因（三条，按证据强度）

1. **训练分布与评测参考风格冲突**：DISC Pair-QA 答案简短（p50 263 字）、52% 带引用且多为概述式，
   LawBench 3-8 参考为中位 396 字 + 具体条文引用。SFT 把输出拉向"短、少引用"，与参考重叠下降。
2. **训练不充分加剧不稳定**：0.68 epoch 被迫中断（OOM 链），复读循环类退化通常随训练继续
   或数据/超参调整变化——但按协议不调参续跑，无法验证该假设。
3. **跨任务判别力受损与 2-2 线"先验坍塌"同族**：1-2 三臂对照 90→60，LoRA 对该 4bit 基座的
   判别任务外溢伤害被再次证实。

## 对下一步的含义

- "用公开咨询 SFT 数据直接 LoRA"在本基座上**两连败**（2-2 同质合成、3-8 真实公开数据），
  共同点是**输出分布被训练集拉偏**。若再试，前置条件应为：目标风格与评测参考对齐的数据
  （如参考答案风格化改写）+ 完整 epoch 训练的内存窗口 + 更小学习率/更长 warmup 的显式授权
  （即新候选、新协议，不在本轮内）。
- LawBench 3-8 全部 500 题未进入训练（冻结规则执行），负结果不影响评测集完整性。
- 服务与内存已恢复：8100/8101 评测服务关闭，oMLX 可正常重新载模型。
