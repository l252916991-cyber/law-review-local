## 5. 业务行为冻结（对照基线）

迁移对照以以下当前行为为准，全部有源码锚点：

1. **策略与检索参数**：[strategy-baseline-20260914.md](../../architecture/strategy-baseline-20260914.md) 继续有效（RRF 常数、权重、邻页扩展、来源配额、模型默认值、embedding revision 语义）。本轮未改动任何运行参数。
2. **运行时拓扑**：原生 DAG（默认，`mode=multi_agent`）与 LangGraph（`mode=langgraph`）双运行时并存；API 入口 `POST /api/cases/{id}/agent-chat`（同步）、`POST /api/cases/{id}/agent-jobs` + `GET /api/agent-jobs/{job_id}`（后台）、`GET /api/agent-runs/{run_id}`（inspect）、`POST /api/agent-runs/{run_id}/resume`（仅 langgraph 可恢复）、`POST /api/cases/{id}/agent-compare`（对照）。`agent_runs.runtime` 区分 native/langgraph。
3. **写入语义**（M2 只读对照的关键约束，计划书 §5.2）：`process_query(..., persist_memory=False)` 只抑制 memories 写入；agent_runs/agent_steps/gap_detections/embedding_cache/audit_log 仍会写。`execute_readonly_tool` 每次调用写 audit_log。因此**现有 API 对照入口不是零写入实验器**；M2 对照必须用隔离副本库 + 只读端口。
4. **失败与恢复语义**：langgraph 失败落 `status=failed` + checkpoint，`resumable` 由 checkpoint 可用性决定；native 运行失败即终态（无恢复）；进程重启时 `init_db(recover_runs=True)` 把残留 running 置 failed、queued/running job 置 interrupted。恢复入口校验案件归属/线程一致，防串案。
5. **权限与审计**：案件级 `require_case_access`/`require_permission`；模型出口白名单 `assert_model_endpoint_allowed`；审计动作名以现有中文动作为准（如 'Agent 阅卷'、'Agent只读工具调用'、'恢复 LangGraph 运行'、'后台 Agent 阅卷'、'Agent 双运行时对比'）。
6. **结果契约**：`process_query` 返回 dict（answer、citations、route、plan、steps、retrieval 指标、validation、llm_used、回退原因、runtime 等），字段级清单在 M1 契约文档中按源码固化。
