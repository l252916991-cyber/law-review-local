# 来源绑定的专家交接与交叉审校

日期：2026-10-26。实施起点：`c63abf953bf10f6f025c2ff22e5819247590e58a`。

## 本批范围

原生 DAG、LangGraph 与 ForgeHarness 隔离候选复用同一专家交接。事实摘录、证据来源、候选矛盾附 `grounding_version=case-findings-v1`、稳定发现编号（事实/矛盾）及原文引用。引用包含文档 ID、页码、原文片段、检索编号和快照摘要；摘要绑定本轮检索的文档/页码/片段/页面文本，不代表原件真实性、数据库全案版本或律师确认。

事实与证据专家仍并行运行。交叉审校读取全部结构化发现，并逐项对照事实摘录与证据条目的来源绑定。疏漏节点通过 `run_specialist` 读取两者对照结果，来源核对不完整时增加待补事项。输入范围标注修正为本轮检索页，不能把最多六页的检索上下文写成全案扫描。

审校模型输入中的专家 JSON 明确标为不可信草稿；法条正文保留在独立核验结果中，不混入案件事实生成提示。报告附录保留全部候选矛盾及待补事项，即使模型概括时遗漏这些内容。模型原始回答先按原引用合同校验，附录的引用不能挽救不合格回答。来源匹配仅检查引用与本轮上下文一致，不验证语义支持、独立印证或金额计算。

`collaboration` 作为同步/后台 Agent 结果与审校轨迹的一部分返回、保存和恢复。缺失、旧版未绑定或待核验的专家结果使协作状态变为 `needs_review`，不准入长期草稿记忆。旧 checkpoint 可读，不猜测补齐旧来源；审校已完成的恢复使用已保存结果，不重复运行专家。新增交接不增加模型/工具调用，沿用现有工具白名单、案件授权与运行限制；未开放每个专家的自主工具循环，也未切换 ForgeHarness 正式产品入口。

受控检索在规范空白和截断显示文本之前记录完整页面的 `page_text_sha256`，该值进入专家快照摘要。LangGraph 恢复前逐页比较当前案件原文的摘要；即使改动位于返回文本窗口之外，也拒绝复用旧分析，且不消耗重试次数。没有完整页摘要的旧 checkpoint 保留原有存在性检查，不冒充具有新版本校验。这不是运行全程的并发锁或全案版本检查。

交接总量超过 40,000 字符明确失败，不静默截掉分歧。无效文档 ID、页码或空引用在构造专家来源时直接拒绝，早于模型调用；原有回答引用检查仍保留。
