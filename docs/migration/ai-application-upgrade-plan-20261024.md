## 2. 每包的验收口径

| 包 | 通过条件 |
| --- | --- |
| A01 | 首 token 前必有 status；引用不出现在 token 流；校验失败发 retract 且不写消息；TTFT 落库 |
| A02 | usage 缺失记 NULL；P50/P95 与手算一致；按 kind/model 分组 |
| A03 | 卷宗/历史/工具返回均标注不可信；工具作用域来自服务端；无写操作审计 |
| A04 | 工具 schema 覆盖白名单；跨案拒绝；预算与轮次上限；端点拒绝 tools 时回退 |
| A05 | initialize/tools/list/tools/call 可用；未知工具不执行；token 模式拒绝启动 |
| A06 | 轨迹接口返回解析后的 input/output；UI 可展开查看 |
| A07/A08 | 题目与其可接受页一致；确定性评分可复算；judge 不可解析不默认通过 |
| A09 | 仅主答案未过校验时回退；回退答案过同一校验；半配置报错 |
| A12 | 视觉失败必回退 Tesseract；不产生空白页；大图拒绝 |

## 3. 非目标

多租户、k8s、模型训练、自动法律结论、通用 Agent 平台化（由 ForgeHarness 承担）。

## 4. 未实施项与原因

| 包 | 原因 | 下一步 |
| --- | --- | --- |
| A10 ANN | 本机无网络安装向量扩展（sqlite-vec/faiss），且计划要求"召回率下降 ≤2pp 才采纳"，缺少 10 万页真实分布无法给出该证据 | 在有依赖与数据集的环境实现；保留精确扫描作对照 |
| A11 前端重写 | 初轮未验证 Node 构建环境；该历史阻塞需重新核实 | 2026-10-25 已纳入正式计划：建立 Next.js/TS 工程，复用 FastAPI API，迁移页面并完成 Playwright、发布验证和入口切换；详见下一步计划 A11.1–A11.4 |
| A13 演示视频/在线体验 | 需要可运行的模型端点与录屏环境，当前不具条件 | 部署一台小主机 + 离线模式录制 3 分钟流程 |

## 5. 放行条件

- 全量离线测试、`ruff`、`mypy` 通过，覆盖率不低于 70%；
- 新增依赖（本轮无）需进锁文件并过 `pip-audit`；
- 任何指标必须可复算，负结果与未验证部分如实记录，不写成"已完成"。
