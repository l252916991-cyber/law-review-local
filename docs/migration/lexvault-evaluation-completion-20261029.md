## 3. 可直接交给两人的独立盲标注包

推荐交接文件：`output/evaluation-completion-20261029/dual-human-handover-v2/reviewers.zip`。其中只有问题、原文来源、使用说明和两份空白模板，隐藏了代理类别、必需要点、草稿答案与自动分数；映射表单独保管，不进入ZIP。来源对象也按白名单投影，不允许额外元数据夹带草稿标签。

这是**数据标签复核包**，没有新题模型输出，不冒充A/B答案质量盲评。每人独立填写：是否可据卷宗回答、是否应拒答、是否存在注入企图，以及自己的参考答案、来源页和理由。两人在标签锁定前不交换结果；分歧由业务复核人裁定。

导入要求不同人员的稳定匿名编号、`independent_human`自述、同一份样本摘要、完整48题标签和本案真实来源页。null、不完整标签、相同复核人、错样本、跨案引用均拒绝；不把空白当一致。程序只计算三个布尔字段的一致率/κ，不自动评估自由文本语义一致，也不证明填表人的真实身份。常量标签下κ不可定义时保持null。

当前结果为 `pending_human_labels`、`kappa=null`、`human_annotation_complete=false`、`business_qualified=false`。首次交接包已由加强白名单后的v2重新生成；推荐只发送v2包。主代理及实现审查方没有查看新题正文；生成标注包的程序读取正文，与候选模型终评的“开启”状态分别登记。目录权限和流程记录不等于防读取的安全系统。

## 7. 统计效力与尚未完成的事项

每类8题是本轮**覆盖目标**。作为量级示例，即使8个独立二项观测全通过，双侧95% Wilson区间也约为67.6%—100%；这不是新封存集的实测成绩。这里按[NIST给出的Wilson方法](https://itl.nist.gov/div898/handbook/prc/section2/prc241.htm)计算，未把该区间当作真实案件总体推断。

若仅作独立二项比例精度规划，用最保守p=0.5、95%正态近似，半宽±10个百分点约需97个独立观测，±5个百分点约需385个；这些只是公式 `ceil(1.96²×0.25/e²)` 的规划示例。当前同案六题存在聚类，三臂又是配对设计；要判断“下降3个百分点”，还必须预登记目标差异、配对不一致率、案件聚类及目标功效并重新规划，不能用97/385或重复调用直接替代。

因此本轮不声称统计效力补完、不声称已经有律师一致性，不声称七维评测体系已完善。剩余事项为两名真实复核人独立标注与裁定、按实际目标重做功效设计、冻结运行时/模型/预算后再开启新集，以及更大规模/更多真实授权案例的检验。产品没有的动态工具链不能靠单轮或规则专家轨迹冒充过程评测。
