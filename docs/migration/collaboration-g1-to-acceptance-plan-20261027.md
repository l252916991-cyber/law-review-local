## 7. U1：律所实际验收

使用管理员、承办、复核、助理、只读五个独立身份，在目标设备执行[原计划 A01–A15](collaboration-release-readiness-plan-20261027.md#8-u1验收用例与证据)。至少覆盖：

- **协作与授权**：跨案查看/下载/导出拒绝、撤去权限但保留角色、停用和令牌轮换；成功流程由对应业务身份执行。
- **办案流程**：建案 → 导入及纠错 → 分工与任务 → 退回及补证 → 冻结预览 → 复核批准 → 指定版本导出 → 归档。并发保存不得静默覆盖，依据变化后必须重审。
- **真实模型与 OCR**：先用合成或获准脱敏样本验证实际推理和扫描 PDF/图片，核对金额、页码、引用支撑与资料不足处理；独立律师记录可接受结果和错误，沿用已有人工复核材料，不用模型替身或 `/models` 返回代替。
- **容量与稳定性**：按事先登记的人数、并发、案件页数、流水量、模型任务及队列场景执行，记录延迟分位数、错误率、积压、资源峰值和恢复时间。
- **值守与恢复**：模拟模型不可用、队列无消费、磁盘阈值和备份失败，实际验证负责人能发现、收到通知并处理；外部巡检或人工值守均须真的投入使用，表格建议不等于已部署。

真实模型尤其远端/付费调用按已确认的数据与预算范围执行。独立复核人尚未参与时，人工验收保持未完成。完成后由业务复核人、运维负责人及交付接收人分别记录结论，再安排正式维护窗口及受控试用。
