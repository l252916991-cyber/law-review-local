## 3. D06 实际模型执行约束

- 推理仅使用获准的合成材料和现有本机服务，不外发、不付费。生成模型固定为 Qwythos 9B；embedding 与 reranker 作为独立模型角色记录，不能只凭名称证明权重身份。
- 临时服务停止后重新启动。为每批运行新建模型清单与 evidence 子目录；先前响应未知的 request/call id 保持 unknown，绝不自动重发。
- 9B 的量化、转换来源或上游 revision 若无法证明，报告中标注未知。模型响应和报告只证明发生了对应推理，不证明法律意见正确。
- 共享输入与独立检索必须使用同一题目、提示词版本、参数、语料快照和权限边界。记录各自检索来源，不把两种设计的差异混成一个分数。
- 负例仍是验收的一部分：无关查询及空案件若被系统接受为有证据的法律结论，则 D06 工程/质量门槛失败；不得改题或删除失败记录来获得通过。
- 若 9B 在当前安全资源限制下仍无法完成，保留完整错误和未知用量状态，停止依赖真实推理的后续题目；继续完成独立的离线实现、发布和文档工作，不关闭守卫或终止其他应用进程。
